# Roadmap

Долгосрочное направление развития. Не дедлайны — а векторы.

## Q1 (next 1-2 месяца)
- **Knowledge depth** — заполнить все 11 разделов до уровня «понятно за 5 минут».
  Метрика: ни одного узла с пустыми полями `details`.
- **Skill coverage** — все повторяющиеся задачи переведены в skills (`skills/`).
  Метрика: 10+ активных skills без перекрытия.

## Q2 (3-4 месяца)
- **Tutorials parity** — для каждого узла категории `основы` есть tutorial
  в `tutorials.js`.
- **AI workflows library** — 5-10 описанных и проверенных сценариев в категории
  `агенты` mindmap.

## Q3 (5-6 месяцев)
- **Scalability checkpoint** — узлов 150+, время рендера ≤ 1.5с на mid-range mobile.
- **MCP coverage** — раздел MCP покрывает: servers (≥ 5 примеров),
  transports, security, patterns.

## Long-term векторы (без сроков)
- **Self-updating knowledge** — автоматический watch за релизами Anthropic,
  предложения новых узлов при появлении фич.
- **Multi-language** — английская версия контента (если будет запрос).
- **Embed в Claude Code** — mindmap как контекст для агента, не только как UI.

## Анти-цели
- ❌ Превращение в «всё про AI вообще» (только Claude и его экосистема).
- ❌ Полный visual redesign без причины.
- ❌ Переход на TypeScript / другой стек без обоснования.
- ❌ Внешние интеграции (DB, auth, accounts) — проект остаётся локальным.
