## Как найти больше похожих

### Метод 1 — Через mutual connections

Открыв profile одного качественного ICP, посмотри "Other profiles viewed" sidebar
и "People you may know". LinkedIn algorithm ИНТЕЛЛИГЕНТНО находит similar people.

### Метод 2 — Через company alumni

Найди ОДНУ компанию в твоей ICP. Через "See all employees" → filter по Product/Ops roles. Все они работают в **прямо ICP-shaped company**.

Хорошие starting points (Nordic):
- **Wolt** (Helsinki — food delivery, ~5000 employees) — alumni now lead products в smaller companies
- **Klarna** (Stockholm — fintech, ~5000 employees) — same pattern
- **Spotify** (Stockholm — too big now, but alumni network golden)
- **Supercell** (Helsinki — gaming, but alumni leadership now in B2B SaaS)
- **iZettle** (Stockholm — acquired by PayPal, alumni network)

### Метод 3 — Через industry conferences

Conferences дают public speakers + sponsor lists:
- [Slush 2026 — Helsinki](https://slush.org/) Nov 18-19
- [Smart Commerce Nordic 2026](https://www.smartcommercenordic.com/) (eCommerce specific)
- [Nordic Growth Summit](https://www.nordicgrowthsummit.tech/)
- [AI Nordic 2026 — Helsinki](https://www.ainordic.com/)
- [Data Innovation Summit Nordics](https://datainnovationsummit.com/region/nordics/)
- [NAMS 2026 — Nordic AI Journalism](https://www.nordicaijournalism.com/nams-2026)

**Action:** open каждую URL → speakers/sponsors page → identify names → LinkedIn lookup.

### Метод 4 — Через newsletter audiences

Twitter / X следишь за этими accounts чтобы видеть кто commentirует / replies:
- [@lennysan](https://twitter.com/lennysan) — Lenny's Newsletter
- [@cagan](https://twitter.com/cagan) — Marty Cagan
- [@shreyas](https://twitter.com/shreyas) — Shreyas Doshi (Product)
- [@andrewchen](https://twitter.com/andrewchen) — Growth

Кто commentariует — это Product/Ops community. Find им в LinkedIn → outreach.

❌ **Не cold-DM** каждого имени из этого файла без research. Karoliina Partanen
получает сотни DMs/week — generic pitch теряется.

❌ **Не блокируй ICP только из этих имён.** Это **examples**, не **target list**.
Real target list — это `01-target-list.md` который ТЫ собрал из LinkedIn searches.

## Что делать

Если хочешь продавать в Finland tech — её network = твой network если ты сделаешь talk на одной из её конференций.
