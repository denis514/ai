## 🔴 Высокий приоритет (мешает уверенно строить)

| # | Находка | Почему важно | Идея решения |
|---|---------|--------------|--------------|
| H1 | **Нет Undo/Redo** | Удалил узел/связь — не вернуть. Для конструктора это тревожно. | Cmd/Ctrl+Z история (хотя бы на nodes/edges). |
| H2 | **«Очистить холст» без подтверждения** | Кнопка X в шапке стирает всё мгновенно, без возврата. | Подтверждение + (после Undo) откат. |
| H3 | **Соединение узлов неочевидно** | Тянуть от точки-хэндла — новичок не догадается. | Подсказка/пульсация хэндлов на первом узле; обучающий шаг. |
| H4 | **Нет проверки перед запуском** | Можно запустить схему без входа/выхода/со связями в никуда → непонятный результат + трата токенов. | Валидация: предупредить «нет стартового узла / есть несоединённые». |

## 🟡 Средний приоритет

| # | Находка | Идея |
|---|---------|------|
| M1 | **Удаление только с клавиатуры** | Кнопка-корзина на выбранном узле / контекстное меню. |
| M2 | **Нет дублирования узла** | «Дублировать» — копирует узел с его инструкцией. |
| M3 | **Окно у узла + боковая панель открываются вместе** | Возможна перегрузка: попап (редактор) и панель (справка) одновременно. Решить: панель сворачивать когда открыт попап, или объединить. |
| M4 | **Тулбокс — только перетаскивание** | Добавить «клик = добавить в центр» (на трекпаде перетаскивать тяжело). |
| M5 | **Не видно, какой узел стартовый** | Явная пометка trigger/«старт» помимо номера 1. |
