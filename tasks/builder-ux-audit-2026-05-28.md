## Лог решений фазы

- **H1 ✅ Undo/Redo** — история nodes/edges (до 50 шагов), Cmd/Ctrl+Z / Shift+Z,
  кнопки в шапке. pushHistory перед: drop, connect, delete, clear, template.
- **H2 ✅ Очистка с подтверждением** — модалка + откат через Undo.
- **H3 ✅ Понятное соединение** — хэндлы крупнее + hover-подсветка; пульсация
  выходного хэндла у несоединённого узла; баннер «как соединять» когда есть
  узлы, но нет связей; tooltip на хэндле.
- **M1+M2 ✅ Панель действий узла** — при выборе узла сверху всплывает
  тулбар: «Дублировать» + «Удалить» (кнопкой, без зависимости от фокуса/клавиш).
  Решает баг «удаление в два клика» (Del подавлялся фокусом в поле промпта).
- _(далее: H4 валидация перед запуском)_

- **✅ Связи: только вперёд + анимация** — isValidConnection (нет связи на
  себя, дубликатов, циклов); кастомная линия при перетаскивании: анимированный
  пунктир «течёт вперёд» + кружок со стрелкой на конце у курсора. Веер из
  нескольких связей от одного выхода работает (React Flow по умолчанию).

## Замечания founder (тест)
- Удаление было неинтуитивным (только клавиша Del + подавление при фокусе) → решено M1.
- Пульсация/увеличение хэндлов: видны только у несоединённых узлов; на шаблонах
  (уже соединены) пульсации нет — это правильно. Возможна задержка деплоя Vercel.

### Flow к Beta (ux-flow-designer)
Главные «дыры» journey: нет pre-run валидации (H4); результат — сырой текст (markdown не рендерится); путь к первому реальному запуску длинный (5+ шагов, 3 модалки); пустые инструкции узлов молча уходят в роль-дефолт.

ТОП-5: (1) **H4 pre-run валидация** [S], (2) **markdown-рендер результата + «что дальше»** [S/M], (3) сокращение пути к первому real-запуску [M], (4) guided-настройка инструкций + значок «настроен» [M], (5) переменные на триггере `{{бренд}}` [L].
