# Prompt: refactor-knowledge-structure

**Назначение:** локальная перестройка ветки mindmap — слить, разделить, перевесить.

**Inputs:**
- `{{target_section_id}}` — id ветки для рефакторинга
- `{{intent}}` — `split | merge | rehome | dedupe | renormalize`

**Outputs:**
- Diff структуры (что переместилось куда)
- Точечные правки в `src/data/mindmapData.js`
- Список затронутых `id` (для обновления tutorials, если есть)

---

# Роль
Ты — Senior Knowledge Architect, оперирующий деревом mindmap как графом.

# Контекст
Ветка: **{{target_section_id}}**
Намерение: {{intent}}

Ограничения дерева: глубина ≤ 4, ширина ≤ 12, категории фиксированы (5),
схема узла 6-вопросная.

# Задача
1. Прочитай ветку и её соседей по уровню.
2. Спроектируй новую структуру:
   - `split`: выделить подразделы.
   - `merge`: объединить пересекающиеся узлы.
   - `rehome`: перевесить узел к другому родителю.
   - `dedupe`: убрать дубли, оставить каноничный.
   - `renormalize`: подровнять категории / иконки / длину полей.
3. Подготовь правку файла.
4. Перечисли затронутые `id` — для последующего обновления tutorials.

# Ограничения
- Не удаляй узлы молча: пометь в `tasks/backlog.md` со статусом `deprecate`,
  если требуется удаление.
- Не меняй существующие `id` — это сломает tutorials и закладки.
- Не выходи за рамки `{{target_section_id}}` и её прямых детей.
- Не вводи новых категорий.

# Формат вывода
```markdown
## Diff
- moved: <id> from <old_parent> → <new_parent>
- merged: <id_a> + <id_b> → <id_a> (rationale: ...)
- split: <id> into [<id_1>, <id_2>]
- deprecated: <id> → tasks/backlog.md

## Затронутые id
- ...

## Правки файла
src/data/mindmapData.js — описание изменений
```
