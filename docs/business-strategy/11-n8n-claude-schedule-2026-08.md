## 1. Что изменилось у n8n с июня (факты, проверено 2026-08-22)

- Инвестиция SAP (май 2026) при оценке **$5.2B** (была $2.5B в окт 2025).
- Позиционирование завершило сдвиг: «AI agent platform», не «автоматизация».
- **11 645 шаблонов** в галерее, с поиском по приложению (Telegram, Gmail…)
  и профилями проверенных авторов.
- **AI Workflow Builder** (текст → готовая схема) — кредиты включены даже в триал.
- Академия: бесплатные курсы, в конце — собранная схема + квиз → **бейдж и
  сертификат**. Прохождение курса = событие удержания.
- MCP в обе стороны: схема n8n может быть инструментом Claude, и наоборот.
- Цены прежние (за запуски, люди/схемы безлимит); LLM — BYOK (модельные токены
  n8n не тарифицирует).

## 2. «Claude Schedule»: Anthropic встроил запуск по расписанию (2026)

Три официальные поверхности:

| Поверхность | Что делает | Кому | Ограничения |
|---|---|---|---|
| **Routines** (Claude Code, апрель 2026) | промпт+репозиторий+коннекторы по cron / HTTP / GitHub-событию, в облаке Anthropic | разработчики | Pro 5 / Max 15 / Team-Ent 25 запусков в день |
| **Cowork scheduled tasks** | сохранённый промпт + каденция, работает даже при выключенном компьютере | все платные планы | результаты только внутри Claude UI |
| **Managed Agents scheduled** (июнь 2026) | серверные cron-агенты через API + credential vault | enterprise/API | beta |

**Вывод-угроза:** «запустить Claude по расписанию» — больше не отличие, это
встроенная функция всех платных планов Claude. Питч «мы даём автозапуск» мёртв.

**Дыры, которые Anthropic оставил открытыми (наши точки опоры):**
1. **Доставка** — ни одна поверхность не присылает результат в Telegram/почту:
   человек должен сам возвращаться в приложение. У нас доставка уже построена.
2. **Нетехническая аудитория** — Routines для разработчиков; Cowork ближе, но
   без направляющих шаблонов и обучения.
3. **Многошаговые визуальные схемы** — у Anthropic всё «один промпт = один
   запуск», без ветвления и композиции.
4. **Обучение «что вообще автоматизировать»** — отсутствует и у Anthropic,
   и (в связке с холстом) у n8n.
5. **Требуется платная подписка Claude** — наш BYOK дешевле для лёгкого
   использования; лимиты Routines (5-25/день) жёстче, чем наша модель.
6. **Язык** — обе экосистемы англо-технические; русский/финский простой язык — наш.

## 3. Параллель трёх продуктов

| | n8n | Claude Schedule | **105 Atlas** |
|---|---|---|---|
| Ядро | холст для разработчиков | расписание внутри Claude | **знание → холст → автозапуск** |
| Учит «что возможно» | академия отдельно от холста | нет | **карта + 261 разбор, связаны с холстом** |
| Шаблоны | 11.6k, по приложениям | нет | 39, по делу/роли — мало, но правильная ось |
| Доставка результата | любые интеграции | нет | **Telegram / почта / календарь** |
| Цена входа | free self-host / €20 | платный план Claude | **бесплатно + свой ключ** |
| Язык | англ. технический | англ. | **ru/fi/en простой** |

Наш незанятый клин (подтверждён разведкой): **«научись и собери» в одном месте,
простым языком, с доставкой туда, где человек живёт**. Ни один из двух гигантов
этого не делает; n8n идёт вниз к нетехническим, Cowork идёт вверх к удобству —
окно открыто, но сужается.

## 4. Короткие идеи (для решения основателем)

**Активация (взято у n8n):**
1. **Шаблон — первый экран.** Пустой холст никогда не первый: галерея «по вашему
   делу» открывается сразу, поиск по делу/приложению. У нас 39 схем — растить
   до 100+ силами тех же разборов.
2. **«Опиши задачу — соберу схему».** Текст → готовая схема на холсте. У n8n это
   платные кредиты; у нас BYOK — себестоимость нулевая. Сильнейший «ага-момент».
3. **Telegram — категория №1 шаблонов** (у n8n Telegram в топе интеграций).

**Удержание (взято у n8n, повёрнуто под нас):**
4. **Сертификат за ЗАПУЩЕННОГО агента**, не за «прослушанный курс» (анти-цель
   «не академия» соблюдена): «мой первый работающий агент» + именной бейдж,
   которым можно поделиться.
5. **Обратный мост схема → разбор**: на холсте у каждого блока — «почему это
   работает» одним тапом (уже есть 30 прямых мостов разбор → схема; достроить
   обратные).
6. **Галерея схем сообщества** (позже, Phase 4/Team): публикация своих схем
   с профилем автора — маховик n8n.

**Позиционирование (против Claude Schedule):**
7. **Питч смещается с «автозапуск» на «доставку и простоту»:**
   «Отчёт сам приходит в Telegram каждое утро — собери за 5 минут без кода,
   на своём ключе». Автозапуск — средство, не заголовок.
8. **Сравнительная страница/блок**: «Claude умеет по расписанию — для
   разработчиков и внутри Claude. Atlas — для всех и с доставкой» (без
   принижения: мы Claude-native и дополняем).
9. **Щедрость лимитов как контраст**: у Routines 5-25 запусков/день на дорогих
   планах; наш BYOK позволяет быть заметно щедрее — сказать это явно.

**Монетизация (подтверждение прежних решений):**
10. Модель doc 08 подтверждается рынком: Free = ручной запуск, Pro = автозапуски
    и доставка. Метрика n8n «за запуски» работает; мы можем считать «автозапуски
    в месяц» ценностью Pro, оставаясь щедрее.
11. **Не строить**: свой хостинг исполнения (SAP-масштаб n8n не наша лига),
    мульти-модельность ради галочки, курсы-как-продукт.

**Риск-часы:** окно «просто и по расписанию для обычных людей» сужается
(Cowork web/mobile в бете). Приоритет идей 1-2-7 — до конца окна.
