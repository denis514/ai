## Модель n8n (факты, июнь 2026)

**Продукт:** node-based workflow automation + AI-узлы (LangChain/AI-agent).

**Ценообразование — за «запуски» (executions), НЕ за людей и НЕ за шаги:**

| Тариф | Цена (год) | Запусков/мес | Хостинг |
|---|---|---|---|
| Starter | €20/мес | 2 500 | Cloud (EU) |
| Pro | €50/мес | 10 000 | Cloud |
| Business | €667/мес | 40 000 | + self-host |
| Enterprise | custom | custom | Cloud / self-host |

- **Пользователей и схем — безлимит на всех тарифах.** «Pay for full executions, not for each step»: 1 запуск всей схемы = 1 execution, сколько бы узлов внутри.
- **AI Workflow Builder credits** отдельным слоем: 50 / 150 / 1000 по тарифам.
- Годовая оплата −17%.
- Enterprise: SSO, RBAC, 200+ одновременных запусков, log streaming, удержание данных, SLA.

**Рост / лицензия:** «fair-code» (source-available, не чистый open-source). Self-host
Community Edition бесплатно → **~191 000 звёзд на GitHub** → сообщество → апселл в
Cloud/Enterprise. Огромная библиотека шаблонов и 400+ интеграций = вовлечение и активация.

## Сходства и отличия с Atlas

| | n8n | Atlas Builder |
|---|---|---|
| Конструктор узлов | ✅ ядро | ✅ почти 1:1 |
| Запуски / расписания / вебхуки | ✅ | ✅ (уже построены) |
| Защита кошелька (caps) | частично | ✅ anti-overlap + дневные лимиты |
| Кто платит за compute | **n8n** (хостит inference/исполнение) | **пользователь** (BYOK — ключ Claude его) |
| Обучение / база знаний | только docs | ✅ **Atlas** (mindmap + курсы, plain-language) |
| Аудитория | разработчики | **нетехнический бизнес-пользователь** (наша ниша) |
| Лицензия | fair-code, open-core | закрытая |

**Стратегический вывод:** BYOK снимает с нас COGS на исполнение (как и в doc 08 vs
Artlist). Значит мы можем быть **щедрее n8n на запуски** и монетизировать не «прогоны как
compute», а **связку знание+конструктор+язык** + автоматизацию (расписания, мульти-ключи,
продвинутые узлы).

## Что взять у n8n — лучшее (приоритезировано)

**1. Ценообразование «за запуски/автозапуски», безлимит людей и схем.** ⭐ вывод №1.
Самая чистая механика: не считаем места и не считаем шаги. У нас уже есть `builder_executions`
+ дневные caps → метрика готова. Нюанс под BYOK: считать тариф лучше по **АВТОзапускам**
(расписания/вебхуки — то, что крутится на нашем сервере без участия пользователя), а не по
ручным прогонам (их пользователь и так оплачивает токенами Anthropic). Ручные прогоны —
бесплатны/щедрый лимит.

**2. Щедрый бесплатный тариф как двигатель роста.** Собрать схему и запускать вручную —
free (BYOK). Платим за: автозапуск, больше одновременных автоматизаций, мульти-ключи,
веер-рассылку, продвинутые узлы (Code-exec, MCP), приоритет.

**3. Библиотека шаблонов как канал активации.** n8n затягивает именно ею. У нас есть
Builder-шаблоны + 261 курс Atlas → лениво лежащий актив. Превратить в растущую,
видимую «галерею готовых автоматизаций + уроков».

**4. Self-host / приватный режим для enterprise.** Продаёт доверие и контроль данных
крупным. Для нас — Phase 5+ (как и в doc 08), не ранний приоритет.

**Чего НЕ брать сейчас:** open-source/fair-code лицензию (отдаёт ядро задёшево, нам на
ранней стадии не нужно и снижает defensibility); managed-исполнение с нашим compute
(ломает BYOK-маржу — см. doc 08).

## Как ложится на наш pricing (черновик, гипотеза)

- **Free** — конструктор + ручной запуск (BYOK), базовые узлы, всё обучение Atlas,
  N бесплатных автозапусков/мес.
- **Pro** — расписания/вебхуки без жёсткого лимита, больше одновременных автоматизаций,
  мульти-ключи, веер-рассылка, приоритет.
- **Team/Enterprise** — общие рабочие пространства, SSO, приватный режим.

Метрика тарифа: **число автозапусков / активных автоматизаций** (не сырые executions).
Это переносит n8n-простоту («платишь за прогоны, безлимит людей/схем») на нашу BYOK-экономику.

## Честная оценка

n8n подтверждает doc 08, не меняет его вектор. Это **усиление**, а не разворот:
BYOK + capability-gate (doc 08) + ценовая простота «за автозапуски, безлимит людей/схем»
(n8n) + flywheel шаблонов. Выручка-ориентир из doc 08 без изменений: $1–4k MRR за 12 мес —
валидация, не бизнес. Все цифры — гипотезы до Phase 0 validation interviews (§15a).
