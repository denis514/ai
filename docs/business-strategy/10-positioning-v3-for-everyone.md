## 1. Тезис позиционирования

**105 Atlas — это AI для всех, а не для разработчиков.**
Единственное место, где обычный человек сначала **понимает**, что ИИ может сделать
именно для его дела, а потом **собирает** это сам — простым языком, без кода и жаргона.

Блогер, владелец барбершопа, репетитор, фермер, мастер-ремонтник — у каждого есть
повторяющиеся задачи (ответы клиентам, записи, напоминания, счета, контент). Сегодня им
некуда пойти: n8n/Zapier слишком технические, ChatGPT требует навыка промптинга, курсы —
пассивны. Atlas закрывает этот разрыв.

## 2. Similar but different (карта рынка)

| | n8n | Zapier / Make | Artlist | ChatGPT / Claude | **Atlas** |
|---|---|---|---|---|---|
| Для кого | разработчики | тех. ops-команды | креаторы | все, но надо **уметь** | **все, вкл. нетехнических и офлайн** |
| Учит, ЧТО возможно | нет (docs) | нет | нет | нет | **да — карта знаний + курсы** |
| Язык | технический | полу-технический | креативный | нейтральный | **простой, без жаргона** |
| Шаблоны | по функциям (HTTP, webhook) | по приложениям | по медиа | — | **по делу/роли** (ответы клиентам, записи, отзывы) |
| Модель | open-core, за прогоны | за задачи/zaps | подписка+кредиты | подписка | **BYOK + за автозапуски** |

**Что берём у них (similar):** визуальный конструктор, библиотека шаблонов,
usage-ценообразование, BYOK (см. doc 08/09).

**Чем отличаемся (наш moat):**
1. **Learning-first.** Мы не просто даём холст — мы **объясняем, что AI может для ТВОЕГО дела** (карта Atlas + 261 курс). Конкуренты предполагают, что ты уже знаешь, что хочешь.
2. **Plain language / ноль жаргона.** Продуктовый принцип, не косметика (см. недавний de-jargon pass: «узел→тема», убрали MCP/magic link).
3. **Шаблоны по роли/делу, а не по технической функции.** Не «HTTP-узел + вебхук», а «автоответ клиентам», «напоминания о записи», «разбор отзывов».
4. **Claude-native + BYOK.** Одна сильная модель, твой ключ, просто.
5. **Охват всей индустрии, включая офлайн.** Реальные жизненные сценарии для тех, кто далёк от IT.

## 3. Честная стратегия входа (beachhead, а не «всем сразу»)

«Для всех» — это **видение и категория (TAM)**, но go-to-market требует плацдарма.
Маркетинг «для всех» = «ни для кого». Поэтому:

- **Видение (north star):** AI-native слой для всех — учит + строит автоматизации простым языком.
- **Плацдарм (с чего ВХОДИМ):** недообслуженный **нетехнический соло-оператор** —
  создатели/блогеры, малый сервисный бизнес (барбершоп, тренер, репетитор, мастер).
  Здесь крупнейший разрыв, и наша связка «обучение + простой язык + конструктор» бьёт точнее всех.
- **Верхний сегмент (doc 02 «Transformation Lead»)** не выбрасываем — он становится
  **одним из сегментов** «всех», обслуживается тем же продуктом позже/параллельно.
- Расширение от плацдарма к «всем» — по мере доказательства (как n8n шёл от dev-сообщества).

**Почему это не противоречит правилу «не академия» (docs/strategy/01-positioning.md):**
обучение у нас — **средство** (понять, что AI может для твоей работы), а не продукт.
Позиционирование — «AI-native OS для всех», обучение встроено, а не продаётся как курс.

## 4. Что меняется в плане разработки (направление)

1. **Шаблоны Builder — переорганизовать по РОЛИ/делу**, не по технической функции.
   Группы вида: «Контент и блог», «Запись и клиенты», «Отзывы и репутация», «Счета и напоминания».
2. **Онбординг-роли** (role-picker уже есть) — добавить нетехнические: создатель/блогер,
   малый бизнес, сервис/мастер — рядом с существующими product/ops/strategy.
3. **Plain-language — жёсткий продуктовый принцип** (продолжать de-jargon во всех новых строках).
4. **Atlas-контент** — добавить use-case узлы для нетехнических и офлайн-профессий
   (реальные сценарии: «парикмахер автоматизирует запись», «репетитор — напоминания»).
5. **Ценообразование** — по doc 09: за автозапуски, безлимит людей/схем, щедрый free
   (BYOK делает это возможным).

## 5. Честная оценка

Расширение аудитории до «всех» — сильное **видение** и реальный белый рынок (нетехнические
люди без хорошего AI-инструмента). Риск — расфокус: без плацдарма «для всех» убивает
ранний продукт. Поэтому: видение = все; **вход = недообслуженный нетехнический соло-оператор**;
доказали → расширяем. Distribution остаётся замороженным (pivot) — это направление
РАЗРАБОТКИ продукта, не запуск маркетинга.
