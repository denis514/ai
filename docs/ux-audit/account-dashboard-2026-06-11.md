# UX-аудит дашборда аккаунта (2026-06-11)

Проведён панелью из 3 экспертов-агентов (информационная архитектура, опыт ученика
JTBD, метрики). Решения подтверждены founder'ом. Реализовано в этой же сессии.

## Диагноз
1. Сайдбар из 9 пунктов перегружен (6 — мелкие настройки).
2. Дубли: вкладка «Активность» = streak+дни (уже в шапке Обзора); Обзор и Обучение
   показывали одни и те же списки.
3. Сырые числа без знаменателя («Изучено: 38» — из скольких?); «На повторение» —
   тупик вместо действия.

## Решения (внедрено)
- **Сайдбар 9 → 3:** Обзор · Обучение · Настройки. «Активность» удалена (огонёк/серия
  в шапке Обзора). 6 настроек (профиль/данные/cookie/поддержка/сессия/удаление)
  свёрнуты в один раздел «Настройки» (стек секций).
- **Hero-метрика:** «Карта Claude изучена на N%» (nodesViewed / всех узлов карты) —
  единственная метрика, охватывающая весь продукт. Кольцо прогресса.
- **Обзор = «вперёд» (действия), Обучение = «назад» (архив/история).** Достижения
  убраны с Обзора (тизер «N из 6» в виджете «Прогресс»; полный список — в «Обучении»).
- **«Продолжить»:** один доминирующий курс (шаг N из M + кнопка «Продолжить»),
  остальные — компактным списком.
- **«На повторение» → кнопка-действие** «Повторить N тем →»; виджет скрыт при 0.
- **Шапка сжата:** убран `totalDays`-vanity; добавлен счётчик «сегодня к повторению».
- **Агенты:** по решению founder'а — полный виджет как есть.
