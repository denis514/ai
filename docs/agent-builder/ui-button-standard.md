# UI: стандарт вторичных кнопок-ссылок (Agent Builder)

> Regulation для Claude. Источник правды по виду вторичных кнопок-действий в Builder.
> Стили — только в `src/builder/BuilderApp.css`. JSX-логику не менять.

## Назначение

Единый нейтральный стандарт для вторичных кнопок-ссылок Builder
(«Как использовать», «Узнать больше в Atlas» и подобные).
Запрещён «светофор»: кнопки не окрашиваются в цвет узла.

## Классы под стандартом

- `.builder-tooltip__link`
- `.builder-tooltip__link--guide`
- `.builder-atlas-link`
- `.builder-atlas-link--guide`
- `.builder-guide__atlas-btn`
- `.builder-preview__atlas-btn`

## Точные значения

Обычное состояние:
- Текст: `color: var(--text)`
- Фон: `background: var(--bg)`
- Рамка: `border: 1px solid var(--border)`
- Иконки наследуют `currentColor`

Ховер (единый для всех, как у `.builder-canvas-btn:hover`):
- `background: var(--surface-2)`
- `border-color: var(--border-strong)`
- Текст остаётся `color: var(--text)` — НЕ перекрашивать в акцент или цвет узла

## Правила

1. В этих кнопках ЗАПРЕЩЕНО использовать `--node-color` и
   `color-mix(... --node-color ...)` для фона, рамки и текста.
   Цвет узла (`--node-color`) применяется только к самим узлам и хэндлам,
   не к кнопкам действий.
2. Модификаторы `--guide` визуально идентичны базовым классам
   (тот же размер, цвет, ховер). Класс можно сохранять, но без цветовой разницы.
3. Две кнопки «Как использовать» и «Узнать больше в Atlas» выглядят ОДИНАКОВО;
   различаются только текстом и иконкой.
4. Все цвета — через токены темы (`--text`, `--bg`, `--surface-2`, `--border`,
   `--border-strong`). Хардкод-цвета (например `#2563eb`) в этих кнопках запрещены.
   Корректность на светлой и тёмной теме обеспечивается токенами автоматически
   (тема переключается через `:root[data-theme="dark"]`).
