# Content Rules

Правила того, **как пишется контент** в узлах mindmap, промптах и tutorials.

## Язык и стиль
- **Язык:** русский. Идентификаторы (`id`) — латиница в kebab-case.
- **Тон:** сухой, профессиональный, без маркетингового пафоса.
- **Лица:** второе («ты»), не «вы», не «мы», не пассив.
- **Без эмоций:** «потрясающий / невероятный / магический» — запрещено.
- **Без воды:** «можно сказать что», «в каком-то смысле», «как мы все знаем».

## 6-вопросная схема (узлы mindmap)
| поле       | вопрос                          | длина          |
|------------|---------------------------------|----------------|
| `what`     | Что это, в одном тезисе         | 1-2 предложения|
| `why`      | Зачем существует / какую боль   | 1-2 предложения|
| `when`     | В какой момент применять        | 1-2 предложения|
| `impact`   | Что выигрываешь от верного применения | 1-2 предложения|
| `example`  | Конкретный пример (фраза/команда)| 1-3 предложения|
| `mistakes` | Антипаттерн / типичная ошибка   | 1-2 предложения|

**Жёстко:** ни одно поле не пустое, не «N/A», не дублирует соседнее.

## Title / icon
- `title` ≤ 30 символов, без точки в конце.
- `icon` — **семантическое kebab-case имя** из реестра `src/components/Icon.jsx`
  (например: `brain`, `tools`, `robot`, `folder`). Эмодзи **запрещены**.
- Если подходящего имени нет в реестре — добавить новую запись в `REGISTRY` в `Icon.jsx`:
  выбрать иконку из `@hugeicons/core-free-icons`, импортировать, дописать
  пару `name: IconComponent` с короткой пометкой соответствия.
- Имя `icon` подбирается по сущности узла, а не по эстетике
  («Контекстное окно» → `scroll`, не `paint`).

## Примеры (поле `example`)
- Хорошо: «Объясни разницу Opus / Sonnet / Haiku и подскажи, какую выбрать
  для аудита 200-страничного PDF.»
- Плохо: «Используй промпт правильно для лучшего результата.»

Примеры должны быть осязаемыми — фраза для модели, команда, конкретный кейс.

## Ошибки (поле `mistakes`)
- Хорошо: «Закидывать 50 файлов "на всякий случай" — модель размывается.»
- Плохо: «Использовать неправильно.»

Антипаттерн — конкретное действие новичка.

## Категории
- 5 фиксированных: `основы / настройка / автоматизация / промпты / агенты`.
- Узел получает категорию по **сущности**, а не по теме разговора:
  «Custom Instructions» — это `настройка`, даже если речь о промптах.

## Запреты
- Дубли узлов.
- Контент категории не соответствует ветке родителя без явной причины.
- Markdown-форматирование внутри полей `details` (это plain text).
- Ссылки на сторонние ресурсы внутри `details` (источники — в README или docs).
- Юмор, мемы, шуточные узлы.

## Tutorials
- Файл `src/data/tutorials.js` — расширенные обучающие модули.
- Связь с mindmap-узлами — по `id`.
- Стиль тот же: сухо, по шагам, с конкретными примерами.
