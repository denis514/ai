# Sound Design — стратегия SFX в 105 Atlas

> Правила для Claude и людей: как добавлять звук в UI, не превращая интерфейс в игровой автомат.

---

## 1. Принципы

1. **Звук — это акцент, не фон.** SFX подчёркивает действие, которое пользователь
   только что совершил. Никакой ambient-музыки, никаких звуков «сам по себе».
2. **Sci-fi minimal, не аркада.** Короткие (≤ 400 мс), тонкие, синтетические:
   blip / whoosh / click / chime. Источник — [mixkit.co/free-sound-effects/sci-fi](https://mixkit.co/free-sound-effects/sci-fi/).
3. **Тихо по умолчанию.** Стартовая громкость `0.3`. Пользователь сам поднимает.
4. **Один звук на одно действие.** Если событие вызывает каскад (раскрыли узел →
   подгрузили потомков → обновился layout) — играем **один** звук, на root-событие.
5. **A11y first.** Звук — никогда не единственный канал обратной связи.
   Всё что озвучено — должно иметь визуальный/тактильный эквивалент.
6. **Тогл всегда видим.** В мини-профиле — переключатель и слайдер громкости.
   `localStorage` ключи: `atlas:sound:enabled`, `atlas:sound:volume`.
7. **Уважение к `prefers-reduced-motion`.** Если включено — SFX по умолчанию выключен
   (пользователь может включить вручную; явный выбор сохраняется).

## 2. Реестр звуков

Источник правды — `src/sound/soundRegistry.js`. Ключи в `dot.case`.

| Ключ                  | Когда играет                                          | Громкость множитель | Длительность |
|-----------------------|-------------------------------------------------------|---------------------|--------------|
| `node.expand`         | Раскрытие ветки в mindmap                             | 1.0                 | ~200 мс      |
| `node.collapse`       | Сворачивание ветки                                    | 0.8                 | ~150 мс      |
| `modal.open`          | Открытие любого модального окна                       | 0.9                 | ~250 мс      |
| `modal.close`         | Закрытие модального окна                              | 0.7                 | ~180 мс      |
| `ui.hover`            | Hover на primary CTA (по желанию, off по умолчанию)   | 0.4                 | ~80 мс       |
| `ui.click`            | Клик по primary CTA                                   | 0.8                 | ~120 мс      |
| `progress.step`       | Завершение шага туториала                             | 1.0                 | ~250 мс      |
| `progress.complete`   | Полное завершение туториала / маршрута                | 1.0                 | ~600 мс      |
| `toast.show`          | Появление toast-уведомления (по желанию)              | 0.6                 | ~150 мс      |

**Запрещено** добавлять SFX без записи в этой таблице.
Любая новая запись → описание `когда играет` + множитель + длительность.

## 3. Файлы и лицензии

- **Хостинг:** `public/sounds/` (self-host, без CDN).
- **Формат:** `.mp3` (универсальная поддержка), 44.1 kHz, mono, 64-96 kbps.
- **Размер:** ≤ 30 KB на файл. Все вместе ≤ 300 KB.
- **Источник:** [Mixkit Sound Effects Free License](https://mixkit.co/license/#sfxFree).
  Атрибуция не требуется, но запрещено перепродавать и встраивать в standalone
  audio products.

Список файлов и mixkit-источников ведётся в `public/sounds/README.md`.

## 4. Engine

`src/sound/soundEngine.js` — singleton:

- `preload(keys?)` — ленивая загрузка по требованию через `new Audio(url)`.
- `play(key, { volume? } = {})` — воспроизводит, ловит `NotAllowedError` молча
  (autoplay-policy до первого user gesture).
- `setEnabled(bool)`, `setVolume(0..1)` — пишет в `localStorage`.
- `subscribe(listener)` — для React-хука `useSoundPrefs`.

**Принципы реализации:**
- Не блокирует main thread: `audio.play()` всегда возвращает Promise — игнорим
  reject.
- Параллельные срабатывания одного ключа: клонируем элемент (`audio.cloneNode()`)
  чтобы не обрезать предыдущее воспроизведение.
- Defer-инициализация: первый `play()` ленится; до этого engine только держит
  prefs.

## 5. React-интеграция

Импорт в любом компоненте:
```js
import { playSound } from '../sound/soundEngine';
// ...
playSound('node.expand');
```

Хук для UI настроек:
```js
import { useSoundPrefs } from '../hooks/useSoundPrefs';
const { enabled, volume, setEnabled, setVolume } = useSoundPrefs();
```

**Где НЕ вызывать `playSound`:**
- В `useEffect` без зависимости от user gesture (autoplay будет заблокирован).
- В render-фазе компонента.
- В loop / частых таймерах (> 5 раз/сек).

## 6. Чек-лист добавления нового SFX

1. Найти подходящий короткий sci-fi звук на mixkit (≤ 400 мс).
2. Скачать MP3, переименовать в `<category>-<action>.mp3` (kebab-case).
3. Положить в `public/sounds/`, добавить запись в `public/sounds/README.md`
   (название + URL источника).
4. Зарегистрировать ключ в `src/sound/soundRegistry.js`.
5. Добавить запись в таблицу § 2 этого документа.
6. Вызвать `playSound('<key>')` в нужной точке кода.
7. Проверить: с выключенным звуком — тишина; с включённым — играет один раз.

---

## 7. Что НЕ делаем

- ❌ Музыкальный фон / loops.
- ❌ Звук на keystroke / scroll / hover массовых элементов (только primary CTA).
- ❌ Голосовые сообщения / TTS.
- ❌ Внешние SDK типа Howler.js — нативный `Audio` достаточно.
- ❌ Звук-only обратная связь без визуального дубля.
