# 105 Atlas

Карта знаний об AI и конструктор AI-агентов в одном приложении.
Три языка: русский, английский, финский. Прод: https://105-atlas.vercel.app

---

## Что внутри

### Atlas — карта знаний
Интерактивная mindmap об AI-native работе и экосистеме Claude.

- **299 узлов** в четырёх слоях: Foundation (основы) → Systems (системы) →
  Transformation (направления перестройки работы) → Use Cases (готовые пути).
- Каждый узел раскрыт по одной схеме: **что это / зачем / когда / как влияет /
  пример / типичная ошибка**.
- **261 обучающий материал** и **13 маршрутов обучения** под разные роли.
- **64 готовых промпта** + библиотека из 42 шаблонов.
- Поиск по всем полям, фильтр по категориям, закладки, прогресс, тёмная тема.
- Zoom, pan, fit-to-screen, expand/collapse; на телефоне — pinch-zoom и drag.

### Agent Builder — конструктор агентов
Визуальная сборка AI-агентов на холсте: перетащил узлы, соединил, запустил.

- **24 типа узлов**: агенты по ролям, инструменты (веб-поиск, файлы, vision,
  память, код, цитаты, MCP), логика (условие, условие-агент, цикл), выходы
  (текст, Telegram, e-mail, Google Calendar).
- **33 готовых шаблона** по индустриям, с переменными в узле «Старт».
- Реальный запуск на своём ключе Anthropic (**BYOK** — ключ хранится
  зашифрованным, у каждого свой).
- **Автозапуск**: по расписанию (разово, каждые N минут, ежедневно, ежемесячно,
  ежегодно) и по вебхуку — работает на сервере, без открытого браузера.
- Пробный прогон без трат токенов, журнал запусков, защита кошелька
  (суточные лимиты + запрет наложения прогонов).

## Стек

- **React 18 + Vite**, чистый CSS, без TypeScript и UI-китов
- **Hugeicons** (только через `src/components/Icon.jsx`)
- **ReactFlow** — холст конструктора
- **Supabase** — вход, база, серверные функции (EU Frankfurt)
- **Vercel** — деплой из `main`

Эталон интерфейса — `/styleguide` (доступен в dev-режиме).

## Структура

```
105 Atlas/
├── CLAUDE.md              # системный файл для Claude Code
├── skills/                # 48 переиспользуемых AI-навыков
├── prompts/ docs/ tasks/  # правила, планы, задачи
├── scripts/               # линтеры, сторожа, генераторы отчётов
├── supabase/functions/    # серверные функции (запуск, планировщик, вебхук)
└── src/
    ├── App.jsx            # Atlas
    ├── components/        # интерфейс Atlas
    ├── hooks/             # pan/zoom, layout, прогресс, тема
    ├── data/              # структура карты, туториалы, маршруты
    ├── locales/           # контент ru / en / fi (ленивая загрузка)
    ├── builder/           # Agent Builder (изолирован от Atlas)
    └── styleguide/        # эталон компонентов
```

Контент карты живёт в `src/locales/<lang>/`, структура — в `src/data/mindmapData.js`.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Для входа и конструктора нужны переменные
`VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` — без них карта работает,
а вход и запуск агентов отключены.

## Сборка и проверки

```bash
npm run build
```

```bash
npm run lint:all
```

Отдельно: `lint:data` (схема узлов), `lint:links` (ссылки внутри текстов),
`lint:builder` (граф конструктора), `lint:css`, `lint:text`, `test:smoke`.

После правки контента обязательно:

```bash
npm run sync
```

Эта команда пересчитывает метки «новое» и «обновлено» — их не правят руками.
