# Russian Language Rubric — детальный чеклист

> Используется агентом `russian-language-pedagogue`.

---

## A. Грамматика русского

### A1. Падежное согласование
- [ ] Управление глаголов: «верить В» (acc), «верить КОМУ» (dat)
- [ ] Управление предлогов: «согласно ПЛАНУ» (dat, не gen),
      «вопреки ОЖИДАНИЯМ» (dat), «благодаря ПОМОЩИ» (dat)
- [ ] Согласование числительных:
      - 1, 21, 31 — nom singular: «1 пользователь»
      - 2-4, 22-24 — gen singular: «3 пользователя»
      - 5-20, 25-30 — gen plural: «10 пользователей»

### A2. Виды и время глагола
- [ ] Совершенный/несовершенный вид — выбран правильно по смыслу
- [ ] «Делать → сделать», «писать → написать» — согласован с
      контекстом (процесс vs результат)
- [ ] Времена согласованы внутри одного абзаца

### A3. Причастия и деепричастия
- [ ] Действительные причастия (-ущий, -ющий, -ащий) уместны
      (не злоупотреблять — звучат канцелярски)
- [ ] Страдательные причастия (-енный, -анный, -тый) согласованы
      в роде/числе/падеже
- [ ] Деепричастные обороты — подлежащее то же что у основного
      глагола («Открыв письмо, ты увидишь...», не «Открыв письмо,
      Claude увидит» если ты открыл)

### A4. Сказуемое
- [ ] Согласование составного именного сказуемого:
      «Claude — это AI» (тире обязательно)
- [ ] Связка «есть» — обычно опускается в настоящем времени
- [ ] Глагольное сказуемое согласовано в роде/числе/лице

### A5. Сложные предложения
- [ ] Корректные союзы: «потому что», «несмотря на то что»,
      «в то время как»
- [ ] Запятые перед союзами «что», «когда», «если», «потому что»
      в придаточных
- [ ] Без избытка «который» — заменять причастиями или новым
      предложением

## B. Орфография и пунктуация

### B1. Орфография
- [ ] Безударные гласные проверяемые ударением
- [ ] Не/ни различаются: «не знаю» vs «никогда не знаю»
- [ ] Слитное/раздельное написание частицы НЕ
- [ ] Одна или две Н в прилагательных/причастиях:
      «истинный», «изученный», но «жареный»

### B2. Пунктуация
- [ ] Запятая перед союзом «что» в придаточном
- [ ] Запятая перед союзом «но», «а», «однако» (если не в начале
      простого предложения)
- [ ] Тире между подлежащим и сказуемым (с пробелами):
      «Claude — это AI»
- [ ] Знаки препинания при причастных оборотах (после
      определяемого слова — выделяется запятыми)
- [ ] Двоеточие после обобщающего слова перед списком
- [ ] Точка с запятой в сложных списках

### B3. Русско-специфичные знаки
- [ ] Кавычки: «...» (ёлочки) для первого уровня,
      „...» для вложенных. НЕ "..." (английские)
- [ ] Тире `—` (длинное) с пробелами для речи и противопоставления
- [ ] Дефис `-` без пробелов в составных словах: «AI-помощник»,
      «пошагово», «по-новому»
- [ ] Многоточие — один символ `…`, не три точки `...`

## C. Лексика и стиль

### C1. Translation-ese (P1, частая)
- [ ] «Это позволяет» → «ты можешь», «так получишь», глагол
- [ ] «У вас есть возможность» → «можешь», «можно»
- [ ] «Является» → опустить или заменить глаголом действия
- [ ] «Выполнить задачу» → «решить задачу», «сделать»
- [ ] «Произвести оценку» → «оценить»
- [ ] «Осуществить процесс» → «провести», «запустить»

### C2. Канцеляризмы (P1)
- [ ] Не «в случае необходимости» — «если нужно»
- [ ] Не «в целях достижения» — «чтобы»
- [ ] Не «производить действие» — «делать»
- [ ] Не «осуществляется» — конкретный глагол

### C3. Англицизмы
- [ ] Технические термины без аналогов — OK: «MCP», «API», «RAG»
- [ ] Бизнес-сленг — расшифровывать или заменять:
      `output` → «результат», `pipeline` → «процесс»
- [ ] Сленг разработчиков — допустим в технических узлах с
      объяснением: «коммит», «пуш», «деплой»

### C4. Точность слов
- [ ] «Адресовать» — кому/чему (письмо адресовано), не
      «адресовать проблему» (англицизм address)
- [ ] «Контролировать» — управлять, не «проверять» (это check)
- [ ] «Реализовать» — осуществить или продать, не «realize»
      («осознать»)
- [ ] «Эффективный» — дающий эффект, не «работающий» (efficient
      ≠ effective)

### C5. Регистр (Atlas-стиль из voice-guide)
- [ ] «Ты» — обращение к одному человеку
- [ ] Не «команды используют», а «ты можешь»
- [ ] Без канцелярских пассивов: не «системой производится»
- [ ] Без академизмов: не «целесообразно», «представляется
      возможным»

## D. Связность и читаемость

### D1. Длина предложений
- [ ] В среднем 10-18 слов
- [ ] Предложение >25 слов — кандидат на разбиение
- [ ] Не более 2 придаточных в одном предложении

### D2. «Который» вирус
- [ ] Не более 1 «который» на абзац (если больше — рефакторить)
- [ ] Заменять причастиями где возможно («задача, которую делает» →
      «задача которая делается» → «задача» + действие)
- [ ] Заменять отдельным предложением для краткости

### D3. Параллельные конструкции в списках
- [ ] Все элементы списка в одной форме (все инфинитивы, или все
      существительные, или все императивы — не смесь)
- [ ] Все элементы начинаются одинаково (с заглавной или с строчной)

### D4. Cohesion
- [ ] Логические переходы: «но», «однако», «при этом», «зато»
- [ ] Без штампов: «как известно», «таким образом» (если можно
      обойтись)
- [ ] Местоимения с чёткими референтами (не «это» в начале абзаца
      без понятного антецедента)

## E. Педагогика русского для Atlas

### E1. Целевой уровень
- [ ] Русский B1+ носителей — понятный обычному пользователю
- [ ] Без слов которые требуют словаря (если можно проще)
- [ ] Технические термины — с расшифровкой при первом упоминании

### E2. Atlas voice-guide (см. docs/voice-guide.md)
- [ ] Пример из жизни в первой фразе what/why
- [ ] «Ты», не «команды»
- [ ] Знакомые якоря (Google, Notion) вместо жаргона
- [ ] Метрики в часах/штуках, не процентах
- [ ] Адресовать страхи, не только описывать возможности

### E3. «Звучит как живой человек»
- [ ] Можно прочитать вслух без спотыкания
- [ ] Не «учебник», не «корпоративный документ» — разговор
      коллеги
- [ ] Если носитель скажет «о, классно написано» — цель достигнута

### E4. Cultural appropriateness
- [ ] Никаких упоминаний российских реалий («Сбербанк» в общем
      контексте)
- [ ] Не «по-русски» как реалия — Atlas — международный
- [ ] Денежные суммы — в долларах ($) если упоминаются (Anthropic
      цены в USD)
